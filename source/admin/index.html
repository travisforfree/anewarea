使用 GitHub 仓库访问令牌登录。令牌只保留在当前页面内存中，刷新或关闭页面后需要重新登录。

第一次使用：如何获取登录令牌
  1. 前往 GitHub 创建细粒度访问令牌。
  2. 设置名称和有效期，选择你的博客仓库。
  3. Repository permissions 中将 Contents 设置为 Read and write；Metadata 保持默认。
  4. 生成后粘贴到上面的输入框。不要填写 GitHub 登录密码。
